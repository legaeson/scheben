# КрасПесок.рф — Супер простая версия сайта

Легковесная, высококонверсионная и быстрая версия сайта для доставки щебня, песка, ПЩС и сыпучих материалов в Красноярске.

## Ключевые особенности
1. **Экстремальная скорость**:
   - Вес всех файлов (HTML + CSS + JS) составляет менее 25 КБ.
   - Никаких внешних тяжелых библиотек, иконочных шрифтов или фреймворков.
   - Мгновенная загрузка даже при слабом мобильном 3G/EDGE в пригородных СНТ.

2. **Максимальное удобство для клиента**:
   - Телефон диспетчера `+7 (995) 075-84-14` и кнопка звонка видны сразу.
   - Кнопка прямого перехода в WhatsApp.
   - Плавающая панель снизу на мобильных («Позвонить» / «Рассчитать»).
   - Экспресс-калькулятор на 1-м экране (материал, объём в клик, район) с отображением итоговой цены в рублях в реальном времени.
   - Каталог с 8 ключевыми материалами, ценами и кнопками «Заказать».
   - Краткие карточки автопарка (Мини 4т, КамАЗ 10т, Самосвал 20м³).
   - Форма заказа всего из 2 обязательных полей (телефон и материал) с маской ввода.

3. **Связь с бэкендом**:
   - Отправка заявок напрямую в существующий обработчик `order.php` / `/api/order`.
   - Если открыто оффлайн или локально через `file://`, пользователю предлагается мгновенный звонок по клику.

## Содержимое папки `simple/`
- `index.html` — основная страница.
- `style.css` — автономные стили.
- `app.js` — калькулятор, маска телефона, обработка отправки.
- `README.md` — данная документация.

## Как запускать и использовать
- **Локально**: просто откройте `simple/index.html` в любом браузере двойным кликом.
- **Через локальный Node.js сервер**: скопировано в `public/simple/` и доступно по адресу `http://localhost:2000/simple/`.
- **На хостинге**: выгрузите папку `simple/` в корень сайта (будет доступно по адресу `https://краспесок.рф/simple/`) либо замените файлы в корне, если решите сделать эту версию основной.
