# Скриншоты UI веб-сайта КрасПесок.рф (Новая полная версия)

В каталоге `ui/` собраны актуальные полноразмерные скриншоты всех 6 страниц обновленной версии сайта в высоком разрешении для ПК (Full HD 1920px) и мобильных устройств (Apple iPhone / Retina 780px).

## 🚀 Интерактивный просмотрщик

Для удобного интерактивного просмотра всех экранов бок о бок с переключением вкладок и режимов:
- **[ui.html](file:///d:/scheben/ui.html)** (или [ui/index.html](file:///d:/scheben/ui/index.html)) — интерактивная галерея в браузере.
- **[ui.pdf](file:///d:/scheben/ui.pdf)** — единый 12-страничный PDF-документ со всеми страницами в оригинальном разрешении.
- **[ui.png](file:///d:/scheben/ui.png)** — обзорная композиция интерфейса (ПК + Мобильная).
